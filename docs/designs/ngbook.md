# NGBook — 漫画与图书双库合一的沉浸式阅读软件

> Initiative 设计文档（持久性参考）。本文档定义愿景、架构与阶段拆分；
> 每个阶段（P1–P5）将各自走一轮 brainstorming → writing-plans 小循环，
> 产出带日期的 phase 设计文档与可执行工作流。

## Problem（问题）

- 看漫画与看图书往往需要安装多个 App，书架、进度、笔记数据割裂。
- 在线阅读类 App 高度依赖源站，商业 App 普遍存在广告、追踪与隐私之忧。
- 本地阅读器与在线聚合阅读器互不兼得：能离线的不聚合，能聚合的不管本地。
- 市面上缺少一个"双库合一、数据完全归用户、界面有辨识度"的开源安卓阅读应用。

## Vision（愿景）

**NGBook**（包名 `com.book.ng`）：一款 GPL-3.0 开源的安卓原生应用，一个 App 满足全部阅读需求。

- **看漫画**：聚合多个第三方漫画源（用户自带），支持搜索、详情、章节在线阅读；翻页与拼页（上下连续滚动）两种阅读模式，体验媲美专业漫画应用。
- **看图书**：EPUB / MOBI / AZW3 / TXT / PDF / CBZ / ZIP 七种格式即导即读；TXT 自动识别 UTF-8 与 GBK；EPUB 大文件按需流式解析，数百兆秒开；解析全部在本地完成，文件不上传到任何地方；翻页与仿真翻页（圆柱卷曲动画）自由切换，仿真模式自动使用水墨楷体，还原纸书质感。
- **管资源**：章节批量离线下载；漫画支持 EPUB / CBZ / ZIP 多格式打包导出；无网络也能随时阅读。
- **记进度**：阅读进度自动记忆续读位置，打开即续读；书架、收藏、笔记、书签本地持久化，数据完全掌握在用户手里。
- **设计语言**：果冻主题玻璃拟态（半透明磨砂层 + 高光胶囊），明暗双模式 × 多种配色，全局 CSS-token 式主题体系。

## Non-Goals（非目标）

| 不做 | 原因 |
|---|---|
| 不内置任何第三方内容源 | 合规底线；采用"用户自带源"模式（legado / Mihon 同款生态） |
| 不做账号体系与云同步 | 本地优先，零上传；WebDAV 备份列入 backlog，不进 v1 |
| 不做 DRM 内容支持（LCP / Adobe） | 目标用户与法律风险面均不需要 |
| 不做 TTS 听书 / RSS 订阅 / 社区功能 | 防止范围蔓延，列入 backlog |
| 不保证用户自带源的可用性 | 源生态由社区/用户自行维护，App 只提供框架 |
| 书源规则引擎不实现 JS 钩子 | 兼容 legado 规则的无 JS 子集，控制复杂度与安全面 |

| 角色 | 职责 |
|---|---|

## Architecture（架构）

经三方案对比（混合引擎 / 全自研 / All-in Readium），选定**方案 A：混合引擎**——
"读"的体验（卷曲动画、楷体排版、果冻主题）自研掌控，"格式的脏活"（EPUB/PDF 流式解析）站在巨人肩上。

```
┌────────────────────────────────────────────────────────────┐
│ UI 层     Jetpack Compose + Material3                       │
│           JellyTheme：明暗模式 × 多配色（玻璃拟态 token 体系）│
├────────────────────────────────────────────────────────────┤
│ 表现层    MVVM：ViewModel + Kotlin Flow + Hilt 注入          │
├────────────────────────────────────────────────────────────┤
│ 领域层    统一内容模型：                                     │
│           BookContent（章节化文本）/ ComicChapter（图片序列） │
│           FormatParser 接口 → Epub/Txt/Mobi/Pdf/Cbz 实现     │
│           进度 / 书签 / 笔记 / 下载 领域服务                  │
├──────────────────────┬─────────────────────────────────────┤
│ 自研 Canvas 文本引擎  │  自研漫画引擎                         │
│ TXT/MOBI/AZW3 排版    │  拼页(上下滚动)/翻页/双页/图片预加载    │
│ 卷曲动画·水墨楷体·主题 │  (CBZ/ZIP/在线章节共用)                │
├──────────────────────┴─────────────────────────────────────┤
│ 渲染依赖    Readium Kotlin（EPUB 流式按需解析 + PDF）         │
│            libmobi JNI（AZW3/KF8 解密还原 → 文本模型）        │
├────────────────────────────────────────────────────────────┤
│ 网络层    OkHttp + 书源规则引擎（JSONPath+Jsoup，legado       │
│           兼容子集）+ ComicSource 适配器接口 + Coil 图片加载   │
├────────────────────────────────────────────────────────────┤
│ 数据层    Room（书架/进度/书签/笔记/下载任务/源配置）          │
│           DataStore（设置项）；文件存 app 专属目录；           │
│           SAF 导入；零上传                                   │
├────────────────────────────────────────────────────────────┤
│ 后台      WorkManager（批量下载 / 导出打包 / 断点重试）        │
└────────────────────────────────────────────────────────────┘
```

**关键选型说明**：

- **EPUB/PDF** → Readium Kotlin 工具包：ZIP entry 级流式读取，不整包解压，满足"几百兆秒开"。
- **TXT / MOBI(PalmDOC)** → 解析为统一文本模型，交自研 Canvas 引擎排版渲染（分页、卷曲、楷体全在此层，行为完全可控）。
- **AZW3(KF8)** → libmobi JNI 绑定（NdkBuilder 集成）；PalmDOC 纯 Kotlin 解析作为 MOBI 7 保底。
- **CBZ/ZIP 漫画与在线漫画** → 自研漫画引擎，图片序列模型统一本地/在线来源。
- **楷体** → 霞鹜文楷（LXGW WenKai，OFL 协议，可随 GPL 应用再分发）。
- **书源格式** → 兼容 legado 书源 JSON 规则的无 JS 子集（自研规则引擎，不复制 legado 代码以规避 GPL 引用纠缠——NGBook 本身 GPL-3.0，仍鼓励回馈）。
- **工程结构** → 单模块清晰分包起步；P4 源系统成熟后拆独立 Gradle 模块。

## HOTL Contracts（契约）

### Intent Contract

```
intent: 构建开源安卓应用 NGBook——图书漫画双库合一的本地优先沉浸式阅读器，
        七格式本地即读、用户自带在线源、离线下载与多格式导出、
        果冻玻璃拟态主题（明暗×多配色）、进度书签笔记全本地持久化。
constraints: 不内置侵权内容源；不上传任何用户文件与阅读数据；
             阶段间产物只增强不破坏（DB 变更走 Room migration）；
             第三方依赖许可证须与 GPL-3.0 兼容；
             全部实现须在沙箱环境内可构建、可自动化测试。
success_criteria: assembleDebug 产出可安装 APK；7 格式样本全部可读且进度可续；
                  卷曲动画与楷体联动可用；章节批量下载后离线可读；
                  导出文件可被第三方工具（unzip/其它阅读器）打开；
                  主题切换全局即时生效；单元测试与 Robolectric 测试全绿。
risk_level: medium（无安全/鉴权/计费核心；风险集中于版权合规边界与工程量）
```

### Verification Contract

```
verify_steps:
  - run tests: ./gradlew testDebugUnitTest（JUnit + Robolectric）
  - check: ./gradlew assembleDebug 成功产出 app-debug.apk
  - check: 格式嗅探测试——7 类样本文件导入书架并正确归类
  - check: TXT 编码测试——UTF-8 与 GBK 样本渲染均无乱码
  - check: 进度持久化测试——模拟进程重启后恢复到上次阅读位置
  - check: 导出物校验——生成的 EPUB/CBZ/ZIP 通过 unzip -t 完整性检查
  - check: 主题切换测试——切换明暗/配色后，Robolectric 断言主题
           token 全局即时生效（无需重启 Activity）
  - check: 书源规则引擎——公版演示源在 JVM 测试下完成
           search → toc → content 全链路
  - confirm: 以上全部通过 + 构建日志无 error；
             真机 UI 体验由产品负责人在阶段验收时确认。
验证环境事实: 沙箱已具备 Java 25 + Gradle 8.14.5；dl.google.com /
             Maven Central / Gradle 发行源网络可达；Android SDK
             cmdline-tools 按需下载；无模拟器，GUI 验证降级为
             Robolectric + 产品负责人真机验收。
```

### Governance Contract

```
approval_gates:
  - 每阶段 phase 设计文档获产品负责人批准后方可进入实施（人工门）
  - 每阶段实施完成、验证契约跑通并向产品负责人演示后，方可进入下一阶段（人工门）
```

## Phase Breakdown（五阶段拆分）

实施顺序采用**本地阅读优先**路线：先把"读"的心脏做扎实，在线源的不确定性后置。

| 阶段 | 主题 | 范围 | 出口标准 |
|---|---|---|---|
| **P1 能读** | 骨架与核心阅读 | 工程搭建（AGP/Kotlin/Compose 版本矩阵、SDK 下载、依赖镜像择优）；JellyTheme 基座；书架页；SAF 导入与格式嗅探；TXT 引擎（UTF-8/GBK 自动识别、分页、翻页/滚动两模式）；EPUB（Readium 集成）；阅读进度记忆 | 导入 TXT/EPUB 能翻页续读；assembleDebug 出 APK；单测全绿 |
| **P2 好看** | 阅读体验 | 仿真卷曲动画（Canvas 圆柱投影，先落地 TXT 引擎）；仿真模式自动切水墨楷体；阅读设置面板（字号/行距/边距/背景）；明暗×多配色完整化；书签 | 卷曲动画流畅且与楷体联动；主题切换全局即时生效 |
| **P3 全格式** | 七格式达成 | PDF（Readium）；MOBI PalmDOC 纯 Kotlin 解析；AZW3（libmobi JNI，NdkBuilder）；CBZ/ZIP + 漫画引擎（拼页/滚动/双页/预加载） | 七格式样本全部可读；漫画两模式体验达标 |
| **P4 聚合** | 在线源框架 | 书源规则引擎（legado 兼容子集）；ComicSource 适配器接口；搜索/详情/章节在线阅读；源管理（导入/导出/禁用）；公版演示源随包用于验证 | 演示源全链路可用；用户导入现成 legado 书源（无 JS 类）可正常聚合 |
| **P5 离线沉淀** | 下载与导出 | WorkManager 批量章节下载（断点/重试/队列可视化）；EPUB/CBZ/ZIP 打包导出；笔记（高亮/批注）；本地备份与恢复 | 无网络环境下已下载内容完整可读；导出物通过第三方校验 |

每阶段启动时各自走：phase 设计文档（`docs/designs/YYYY-MM-DD-phase-N-<slug>-design.md`）→ writing-plans 工作流 → 实施 → 验证 → 演示验收。

## Risks & Open Questions（风险与开放问题）

| # | 风险 | 等级 | 缓解 |
|---|---|---|---|
| R1 | 沙箱需现下 Android SDK（约 500MB），首次构建耗时 | 低 | 直连 dl.google.com 已验证；慢则切国内镜像（D9） |
| R2 | EPUB（WebView 渲染）卷曲动画效果存在不确定性 | 中 | P2 先在自研 TXT 引擎落地卷曲（确定性高）；EPUB 卷曲降级为翻页+淡入，P3 后评估 |
| R3 | libmobi JNI 引入 NDK 构建复杂度 | 中 | MOBI PalmDOC 纯 Kotlin 保底先行；AZW3 作为独立小步提交，失败不阻塞其余六格式 |
| R4 | legado 规则子集无法覆盖含 JS 钩子的复杂书源 | 中 | 边界在文档明示"无 JS 子集"；P4 演示源验证全链路；社区反馈驱动后续扩展 |
| R5 | 无模拟器，UI 观感无法在沙箱内验证 | 中 | Robolectric 覆盖交互逻辑；每阶段交付可安装 APK，真机验收设为人工门 |
| R6 | 超大 EPUB 打开性能不达标 | 低 | Readium 本身流式设计；验收口径为打开耗时不随文件体积线性增长 |

**开放问题**（进入对应阶段设计时裁定，不阻塞本 initiative）：

- Q1（P1）：AGP / Kotlin / Compose BOM 与 Gradle 8.14.5、Java 25 的确切版本矩阵，以及 minSdk / targetSdk 取值。
- Q2（P2）：霞鹜文楷随包分发（约 15MB）还是首启按需下载——体积与离线可用性的权衡。
- Q3（P4）：漫画源适配器接口是否兼容 Tachiyomi 式源扩展生态，还是仅 NGBook 自定义格式。
- Q4（P5）：备份恢复是否需要跨设备迁移格式（PC 端工具支持）列入 backlog 评估。
